🔍 2. Консольный диф-инструмент
Скрипт собирает вычисленные стили ключевых элементов. Селекторы подобраны так, что работают на обеих страницах (структурные — для шапки, классовые — для остальных блоков; у оригинала и плагина они совпадают).
Откройте страницу, F12 → Console, вставьте и нажмите Enter:


(() => {
  const rows = [
    ['title', '.webinar-widget h2'],
    ['subtitle', '.webinar-header h2 + p'],
    ['divider', '.webinar-header h2 + p + div'],
    ['desc', '.webinar-header h2 + p + div + p'],
    ['pdf-btn', '.webinar-materials a'],
    ['tabbar', '.webinar-tabbar'],
    ['tab-active', '.webinar-tab-btn.active'],
    ['tab-inactive', '.webinar-tab-btn:not(.active)'],
    ['tab-content', '.webinar-tab-content.active'],
    ['video-col', '.webinar-col-video, .center-webinar-column'],
    ['timeline-col', '.webinar-col-timeline, .right-webinar-column'],
    ['video', '.webinar-widget video'],
    ['views', '.webinar-views'],
    ['timeline', '.webinar-timeline-list'],
    ['tl-item', '.webinar-timeline-item'],
    ['tl-time', '.webinar-timeline-time'],
    ['tl-title', '.webinar-timeline-title'],
    ['tl-desc', '.webinar-timeline-desc'],
    ['details', '.webinar-details-wrap'],
    ['details-summary', '.webinar-details-summary'],
    ['detail-block', '.webinar-detail-block'],
    ['detail-time', '.webinar-detail-time'],
    ['detail-p', '.webinar-detail-block p'],
    ['takeaways', '.webinar-takeaways-grid'],
    ['takeaway-li', '.webinar-takeaways-grid li']
  ];
  const props = ['display','fontSize','fontWeight','lineHeight','letterSpacing','color','backgroundColor','marginTop','marginBottom','marginLeft','marginRight','paddingTop','paddingBottom','paddingLeft','paddingRight','flexBasis','flexGrow','flexWrap','gap','columnGap','borderRadius','borderBottomWidth','borderBottomColor','boxShadow','maxWidth','minWidth','justifyContent','alignItems'];
  const out = { url: location.href, viewport: innerWidth, items: {} };
  rows.forEach(([name, sel]) => {
    const el = document.querySelector(sel);
    if (!el) { out.items[name] = 'NOT FOUND'; return; }
    const cs = getComputedStyle(el);
    const r = el.getBoundingClientRect();
    const o = { w: Math.round(r.width), h: Math.round(r.height) };
    props.forEach(p => { o[p] = cs[p]; });
    out.items[name] = o;
  });
  const json = JSON.stringify(out, null, 1);
  console.log(json);
  if (window.copy) copy(json); // � Chrome ����� ����� � ����� ������
})();


📋 Как используем
Откройте оригинальную страницу → консоль → скрипт → результат в буфере → вставьте мне
Откройте страницу с плагином → то же самое → вставьте мне
Важно: одинаковая ширина окна на обеих страницах (например, 1600px) и одинаковая роль (оба как гость или оба авторизованы)
Я сравню два дампа и выдам один финальный набор CSS-правок, закрывающий все расхождения разом — включая мобильные (прогоним второй раз на ширине ~480px). Больше не будем искать по крупинке!
